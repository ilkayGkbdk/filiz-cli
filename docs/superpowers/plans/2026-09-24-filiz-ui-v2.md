# Filiz UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend Filiz with tabbed workspaces, mouse-aware scrolling, hideable panels, theme presets, richer resource details, and a dedicated Network/Download workspace.

**Architecture:** Keep collection and snapshot production independent from rendering. Add a UI navigation state containing workspace, focused panel, visible panels, layout density, theme, and scroll offsets; render each workspace from the same snapshot. Extend network collection with rates, totals, peaks, and bounded connection summaries without making mouse support mandatory.

**Tech Stack:** Rust 2021, Ratatui 0.29, Crossterm 0.28, sysinfo 0.32, existing Filiz snapshot/collector model.

**Spec:** `docs/superpowers/specs/2026-09-24-filiz-ui-v2-design.md`

## Global Constraints

- Main navigation uses upper tabs and number keys `1`–`5`.
- `Tab` changes panel focus; `H` hides/shows the focused panel; `L` cycles compact/balanced/spacious density.
- Mouse wheel scrolls only the focused scrollable panel; keyboard navigation remains complete when mouse support is unavailable.
- Missing measurements render `N/A` and never become fabricated zero history samples.
- The default palette is Forest; additional themes are Amber, Mono, and Solarized.
- Destructive process actions retain explicit confirmation and self-target protection.
- Compact terminals prioritize critical values and keep notices visible.
- Required checks remain `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, and `cargo build --release`.

## Planned File Structure

- `src/ui/state.rs`: workspace, focus, panel visibility, density, theme, and scroll state.
- `src/ui/theme.rs`: theme enum and palettes.
- `src/ui/mod.rs`: workspace routing, responsive layout, mouse-aware rendering.
- `src/ui/widgets.rs`: tab bar, workspace widgets, metric detail rows, scroll indicators, and menus.
- `src/app.rs`: input dispatch, mouse events, workspace commands, and UI state integration.
- `src/model.rs`: richer resource and network summary types.
- `src/collectors/system.rs`: network totals, peaks, and interface-aware measurements.
- `src/collectors/processes.rs`: process traffic/connection summaries where available.
- `src/collectors/mod.rs`: snapshot assembly for expanded network data.
- `tests/ui_tests.rs`: workspace, theme, density, scroll, and compact render coverage.
- `tests/collector_tests.rs`: network rate/total/peak conversion coverage.
- `README.md`: v2 controls and workspace documentation.
